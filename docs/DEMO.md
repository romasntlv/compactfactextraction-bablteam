# Живая демонстрация

1. До защиты скачайте веса и образ из Release, выполните инструкции README. Учитывайте архитектуру ARM64 готового образа; на x86_64 заранее соберите Dockerfile.
2. Запустите HTTP-сервис и дождитесь `GET /health` → ready.
3. В другом терминале выполните `python3 tools/demo.py`.
4. Скрипт покажет исходный звонок, отправит настоящий HTTP-запрос, выведет JSON, фактическое время и признак partial. На CPU Docker ранее один запрос занимал 27–39 секунд; не обещайте мгновенный ответ.
5. Покажите связь `source.turn_idx` с репликой и различие `valid_from`/`valid_to`. Не называйте каждый сгенерированный факт правильным без проверки.
6. При желании повторите с `--input path/to/call.json` — один JSON-звонок без facts.

`benchmarks/http_docker_cpu.jsonl` содержит ранее полученные реальные HTTP-ответы. Это архивный пример, а не live demo; при техническом сбое обозначайте его именно так. Скрипт не подставляет сохранённые ответы.
