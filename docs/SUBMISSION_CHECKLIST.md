## Существенные границы проверки

Повторный val упакованной сборкой не завершён. Linux x86_64 и CUDA Docker не проверены. Готовый Docker-образ имеет архитектуру ARM64, это явно указано в имени и README; для других платформ дан Dockerfile. Исходный val и новый dev нельзя представлять как один запуск. Все указанные границы сохраняются в сдаче.
